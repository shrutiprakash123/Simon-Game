# Simon Game 🎮

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. The Simon Game challenges players to remember and repeat an increasingly long sequence of colors and sounds.

## 🚀 Features

- Interactive colored buttons.
- Randomly generated color sequences.
- Sound effects for each button.
- Increasing difficulty as the player progresses.
- Keyboard and mouse interactions (if enabled in the implementation).
- Game-over feedback when an incorrect sequence is entered.

## 🛠️ Technologies Used

- **HTML5** — Structure of the game.
- **CSS3** — Styling and visual effects.
- **JavaScript** — Game logic, sequence generation, and user interaction.
- **jQuery** — DOM manipulation and event handling.

## 🎯 How to Play

1. Start the game.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the colored buttons in the same order.
4. Each new level adds another step to the sequence.
5. Continue remembering the pattern and try to reach the highest level possible!

## 💡 What I Learned

- Generating random sequences using JavaScript.
- Managing arrays and game state.
- Using functions to organize game logic.
- Implementing audio effects and button animations.
- Using jQuery to handle user interactions.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Follow the on-screen instructions to play.
